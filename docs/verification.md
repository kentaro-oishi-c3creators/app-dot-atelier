# 検証結果

実施日：2026-10-10

## 成功した確認

- TypeScriptの型検査・Vite本番ビルド成功。
- ロジックテスト4件成功：下絵の保存・復元、塗りつぶし境界、線の連続性、不正編集データ拒否。
- 公開用 `dist/` を `/dot-atelier/` に配置した静的サーバーでブラウザテスト4件成功。
- PC（1440px）とスマホ相当（390px・タッチ入力）の2構成で、描画→取り消し→やり直し→再読み込み後の作品復元を確認。
- PNGのファイル署名と32×32サイズ、透明ピクセルを確認。
- 編集JSONの書き出し、新規16×16作品への変更、JSON読み込みで元の絵を復元。
- 冒険者からねこへの切り替え、塗りつぶし、消しゴム、マス目、拡大、利用ガイドへのリンクを確認。
- 390pxの画面でページの横はみ出しなし。
- メイン操作のブラウザ例外なし。

## 修正した点

PCの原寸キャンバスが高さ制限で一部隠れていたため、拡大時にだけスクロール領域の高さを制限。ダイアログにフォーカス移動、Tabの循環、Escapeで閉じる処理を追加。

ブラウザテストの合成PointerEventではpointer captureに必要な実ポインターが存在しないため、実マウスクリック・タッチ入力へ修正。道具選択後のスクロールを考慮してキャンバスの表示位置を更新。

## 検証の範囲

ChromiumのPC・スマホエミュレーションを使用。実機iPhone/Safari・Android/Chromeでのファイル保存挙動は未確認。自動保存は端末・ブラウザ別。AI画像生成・レイヤー・PNG読み込みは初版の対象外。

GitHubリポジトリの作成とGitHub Pages本番デプロイは、新規作成権限の不足により保留。2026-10-10時点で作成APIは403、予定リポジトリは404。ローカルのビルド成功は本番公開の成功を意味しない。

## 再現

```sh
npm ci
npm test
npm run build
npm run dev
# 別ターミナル：/usr/bin/chromium がある環境
npm run test:browser
```

本番相当では、`dist/` を `dot-atelier/` の下に置く静的サーバーに対して `APP_URL=http://127.0.0.1:4173/dot-atelier/ npm run test:browser` を実行。
