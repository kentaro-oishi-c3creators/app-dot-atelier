DOT ATELIER / はじめてのドット絵

ひとマスから、はじめよう。

絵の経験はなくても大丈夫。下絵の髪や服の色を変えるところから始められます。

まずはこの4ステップ

  1. 冒険者・ねこ・ハートから下絵を選ぶ。
  2. 色を選び、ペンでキャンバスをタッチ。指を動かすと続けて描けます。
  3. 失敗したら「元に戻す」。消しゴムで消すと透明になります。
  4. 「PNGで保存」で完成。原寸はゲーム素材、4倍・16倍は見せる用途に。

道具とスマホ操作

塗りつぶしは同じ色でつながった部分をまとめて変更。「色を拾う」は絵の色を選び、そのままペンに戻ります。＋から好きな色も選べます。

スマホも指で描けます。キャンバスの拡大ボタンを押すとマスを大きく表示。拡大時はキャンバスの端・スクロール領域で見える位置を移動してください。マス目のボタンで線を隠せます。

作品を残す

作品は今の端末のブラウザに自動保存。ページを開き直しても続けられます。履歴は再読み込みで消えます。作品を切り替える前や大事な節目には「編集データを保存」で .dot.json を保存してください。「編集データを読み込む」で再開したり、別の端末へ移動したりできます。

PNGは完成画像、編集データは続きから描くためのファイル。ブラウザのデータ消去やプライベートモードでは作品が残らない場合があるため、大事な作品はファイルでも保存してください。

新しい作品

16×16・32×32・64×64の空白キャンバスも選べます。下絵への切り替え時には確認が表示されます。切り替え後は「元に戻す」で直前の作品へ戻れます。

AIと一緒に作る

  1. 「雛形を渡して、AIと作ろう」で今の作品・空の雛形・キャラクター・アイコンからJSONを選ぶ。
  2. お願いしたいことを書いて「プロンプトを作る」。コピペエリアを自由に編集し、コピーしてAIのチャットに貼り付ける。
  3. AIが返したJSONを「AIのJSONを貼り付け」に入れて読み込む。切り替え前に確認が表示されます。

「Markdownで保存」はプロンプトと選択したJSONを1つの.mdファイルにまとめます。「JSON雛形を保存」は編集データのみ。AIとの会話は手動で行い、AIが返したデータは件数や色の形式を確認してから読み込みます。

クラウドに保存する

「作品をクラウドに残そう」でメールアドレスとパスワードを新しく登録。確認メールを承認してログインすると、自分専用の作品一覧を使えます。「クラウドに新しく保存」は現在の作品のコピーを保存します。一覧の「開く」は確認後にキャンバスへ反映。「現在の作品で上書き」と「削除」も確認してから実行されます。最大100件です。

編集中の自動保存は端末内で続きます。クラウド保存はボタンを押した時点の内容なので、別端末へ移る前に保存してください。保存失敗の表示が出た場合はJSONもダウンロードしておきましょう。

Google Driveの接続設定

Googleのアプリ用クライアントIDが設定済みなら「Google Driveに接続」で許可し、Driveの「Dot Atelier」フォルダへJSONを保存できます。アプリから作成したファイルの新規保存・読み込み・上書き・ゴミ箱への移動に対応します。接続の期限が切れたら再接続してください。アプリの作品一覧とDriveは別の保存先で、自動で複製しません。

  1. Google Cloud Consoleでプロジェクトを作り、Google Drive APIを有効にする。
  2. 「OAuth 同意画面」でアプリ名「Dot Atelier」、サポートと連絡先メールを入力。対象は「外部」。テストユーザーに使うGoogleアカウントを追加。
  3. 「データアクセス」で https://www.googleapis.com/auth/drive.file を追加。
  4. 「クライアント」でウェブアプリを作成し、承認済みJavaScript生成元に https://kentaro-oishi-c3creators.github.io を登録。リダイレクトURIは不要。
  5. 公開クライアントIDをアプリの設定に反映する。クライアントシークレットは不要。

保存場所

現在の作品1件とプロンプトの下書きは、この端末のこのブラウザ内に自動保存されます。JSON・PNG・Markdownのファイル保存先は、ブラウザやスマホのダウンロード先です。複数作品はクラウドに保存するか、切り替え前にJSONを保存してください。GitHubにはアプリのソースがあり、作品はアップロードされません。端末内の自動保存は同期されませんが、クラウドに保存した作品は同じアカウントから別端末でも開けます。

このプロジェクトについて

画像編集が初めての人向けに、キャラクター制作、次にアイコン制作を目標として作成。React + TypeScript + Viteで動作する静的Webアプリです。初版は手動編集と固定下絵に対応し、AI画像生成・PNG読み込み・レイヤー・アニメーションは拡張候補です。

ソースと資料の正本はGitHubで管理。Driveには初期方針と引き継ぎ資料を配置します。
