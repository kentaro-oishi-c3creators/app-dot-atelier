# DOT ATELIER：企画と決定事項

作成日：2026-10-10

## 会話から決まった目的

「ドット絵を作るスキルを作れるか」から検討を開始。優先順位はキャラクター、次に実用性のあるアイコン。生成した下地を自分で編集して完成する体験を目指す。

ユーザーは画像編集の未経験者。専門ソフトの操作を前提にせず、ブラウザで大きなマスを塗るWebアプリを先に作る方針とした。スキルはAI側の制作手順、Webアプリは本人が絵を編集する場所、という役割分担。

依頼された管理方針：今回用のGitHubリポジトリを新設し、ソースと最終的なドキュメント群をGitHubで管理、GitHub Pagesにデプロイ。スマホでも使える構成。Driveにも今回の内容を適切な場所へ配置する。

## 初版の体験

1. 冒険者・ねこ・ハート、または空白キャンバスを選ぶ。
2. ペンと色でマスを塗る。消しゴム、塗りつぶし、色を拾う道具も使える。
3. 失敗したら元に戻す。自動保存に加え、編集データをバックアップする。
4. 完成したら透明背景のPNGで保存。

React + TypeScript + Vite を採用。Next.jsのサーバー機能を必要とせず、GitHub Pagesへ静的配信できるため。

## 拡張候補

- キャラクター下絵の種類追加、アイコン向けテンプレートの充実
- PNG読み込み、パレット書き出し、部品・レイヤー管理
- 言葉でキャラクターを生成してから編集する機能
- アニメーション・スプライトシート

AI生成を追加する場合は、APIキーをブラウザに置かず別途サーバー側の設計が必要。初版には外部生成APIを組み込まない。

## ドキュメントの正本

GitHubリポジトリの `docs/` と README が更新対象。Driveには初期方針と完成時点の資料を保存し、GitHubへの入口として使う。自動双方向同期は行わない。
